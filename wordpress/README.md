# افزونهٔ وردپرس Damoon Signal

ستاپ‌ساز کریپتو برای وردپرس: موتور قانون‌محور، جهت، ورود، حد ضرر و هدف را از کندل‌های بسته‌شدهٔ Binance حساب می‌کند،
همه را در یک کارنامهٔ شفاف و غیرقابل‌حذف ثبت می‌کند و نتیجه‌ها را خودکار می‌سنجد. فقط برای آموزش و معاملهٔ کاغذی است.

> ⚠️ این تحلیل‌ها قطعی نیستند و توصیهٔ مالی نیستند.

## نصب و به‌روزرسانی

```bash
cd wordpress && ./build.sh        # فایل‌های dist/damoon-signal-<نسخه>.zip و dist/damoon-boost-<نسخه>.zip ساخته می‌شوند
```

در پیشخوان وردپرس: افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل zip ← «جایگزینی نسخهٔ فعلی با نسخهٔ بارگذاری‌شده».
لازم نیست افزونه را غیرفعال کنید. کارنامهٔ قبلی حفظ می‌شود و جدول‌ها هنگام اولین بارگذاری خودکار ارتقا پیدا می‌کنند.

شورت‌کدها:

| شورت‌کد | کار |
|---|---|
| `[damoon_signal]` | ستاپ‌ساز (انتخاب نماد و تایم‌فریم، نمودار، سطوح) |
| `[damoon_record]` | کارنامه: آمار، منحنی تجمعی R، جدول همهٔ سیگنال‌ها |
| `[damoon_scan tf="4h" theme="dark"]` | «اسکن زندهٔ ربات»: آخرین وضعیت هر نماد (خرید / فروش / خنثی)، قیمت و تغییر ۲۴ ساعته |
| `[damoon_pulse theme="dark"]` | «نبض بازار»: حجم نظرات شبکه‌های اجتماعی، نسبت خرید/فروش، نظرات هم‌سو با ربات، اخبار و شاخص ترس و طمع، به‌صورت زنده |

## افزونهٔ Damoon Boost — سرعت، امنیت، سئو (۱.۰.۰)

افزونهٔ جدا برای کل سایت (`dist/damoon-boost-<نسخه>.zip`)؛ در «تنظیمات ← دامون بوست» هر مورد جدا خاموش/روشن می‌شود
و جدول «وضعیت سایت» مشکل‌های رایج را نشان می‌دهد (HTTPS، بسته‌بودن سایت برای گوگل، پیوند یکتا، کش، کرون، DISALLOW_FILE_EDIT،
کاربر admin، نسخهٔ PHP، WebP).

| بخش | کارها |
|---|---|
| سرعت | حذف ایموجی، wp-embed، jquery-migrate (همان پیام JQMIGRATE)، dashicons مهمان و تگ‌های اضافی head؛ Heartbeat کم‌مصرف؛ preconnect؛ defer اختیاری اسکریپت‌ها (jQuery، وابسته‌هایش و اسکریپت‌های دارای کد inline defer نمی‌شوند) |
| امنیت | هدرهای امنیتی و HSTS، بستن کامل XML-RPC، بستن فهرست کاربران REST برای مهمان و ‎?author=‎ و صفحهٔ نویسنده، ۵ تلاش ورود ناموفق = ۳۰ دقیقه قفل، پیام خطای یکسان ورود، خاموش‌کردن Application Passwords |
| سئو | توضیح متا (صفحهٔ اصلی برای هر زبان جدا)، Open Graph و کارت X (پیش‌نمایش لینک در تلگرام)، og:locale برای سه زبان، داده‌ی ساختاریافتهٔ WebSite و Organization، noindex نتایج جست‌وجو، robots.txt، حذف کاربران از نقشهٔ سایت، بستن صفحه‌های پیوست |

اگر Yoast، Rank Math، AIOSEO یا SEOPress فعال باشد، بخش سئو خودکار کنار می‌رود تا تگ تکراری ساخته نشود.
دامون سیگنال هم از این نسخه استایلش را در head بارگذاری می‌کند (بدون جابه‌جایی صفحه) و اسکریپتش defer است.

## استقرار روی سرور خارجی (پوشهٔ `deploy`)

1. **nginx:** `deploy/nginx-wordpress.conf` — HTTPS و انتقال www، IP واقعی پشت Cloudflare، کش صفحهٔ FastCGI
   (کاربر واردشده، سبد خرید و پیشخوان کش نمی‌شوند؛ هدر `X-Cache`)، gzip، کش یک‌ساله فایل‌های ثابت، محدودیت تلاش ورود و REST،
   بستن xmlrpc.php، wp-config.php، فایل‌های مخفی و اجرای PHP در uploads. روی nginx واقعی با PHP-FPM و وردپرس امتحان شده است.
2. **wp-config:** خط‌های `deploy/wp-config-production.php` (دیباگ خاموش، DISALLOW_FILE_EDIT، کرون واقعی و…). کلیدهای امنیتی را تازه بسازید.
3. **کرون:** `* * * * * cd /var/www/damoon && php wp-cron.php > /dev/null 2>&1` (کاربر www-data).
4. **Cloudflare:** پراکسی نارنجی روشن؛ SSL/TLS = Full (strict)؛ Always Use HTTPS؛ Brotli و HTTP/3 روشن؛ Rocket Loader **خاموش**
   (اسکریپت‌ها را خراب می‌کند). برای اینکه کسی Cloudflare را دور نزند، روی سرور پورت ۴۴۳ را فقط برای IPهای Cloudflare باز کنید.
5. **سرور:** PHP 8.3 با OPcache، و ترجیحاً Redis + افزونهٔ Redis Object Cache. افزونه‌ها و قالب را به‌روز نگه دارید و
   افزونه‌های غیرفعال را حذف کنید. پشتیبان‌گیری روزانه از دیتابیس و wp-content.

- **تشخیص خودکار زبان بازدیدکننده** (تنظیمات ← زبان و تشخیص خودکار):
  1. کشور بازدیدکننده از هدر CDN (`CF-IPCountry` کلادفلر، CloudFront یا GeoIP سرور) و جدول «کشور ← زبان»؛
  2. اگر کشور در جدول نبود: زبان مرورگر (`Accept-Language`)؛
  3. در غیر این صورت: زبان پیش‌فرض.
- هدایت فقط **بار اول** و در مرورگر انجام می‌شود (با کش صفحه سازگار است) و نتیجه در کوکی `damoon_lang` یک سال می‌ماند؛
  اگر بازدیدکننده بعداً زبان را دستی عوض کند، دوباره هدایت نمی‌شود. ربات‌های گوگل و ابزارهای تست هدایت نمی‌شوند تا سئوی هر زبان سالم بماند.
- مقصد هدایت، نسخهٔ ترجمه‌شدهٔ **همان صفحه** است (لینک‌های hreflang که Polylang می‌سازد)؛ اگر صفحه ترجمه نداشته باشد، بازدیدکننده همان‌جا می‌ماند.
- مسیر REST تازه: `GET /wp-json/damoon/v1/geo-lang` (هرگز کش نمی‌شود).

### راه‌اندازی روی سرور خارجی

1. افزونهٔ **Polylang** را نصب کنید؛ زبان‌ها: فارسی (`fa`)، English (`en`)، Русский (`ru`). در تنظیمات Polylang گزینهٔ
   «Detect browser language» را **خاموش** کنید (تشخیص را این افزونه انجام می‌دهد).
2. هر صفحه (صفحهٔ اصلی، صفحهٔ ربات و…) و منوها را برای هر زبان ترجمه کنید و سوئیچر زبان Polylang را در منو بگذارید.
   شورت‌کدها در هر ترجمه همان هستند و خودشان به زبان صفحه نمایش داده می‌شوند.
3. دامنه را پشت **Cloudflare** (پراکسی نارنجی) قرار دهید تا هدر کشور به سرور برسد. بدون آن، تشخیص با زبان مرورگر انجام می‌شود.
   وضعیت تشخیص برای مرورگر خودتان در بالای صفحهٔ تنظیمات افزونه نمایش داده می‌شود.
4. ثابت‌های `WP_PROXY_*` که برای سایت لوکال در ایران در wp-config گذاشته بودید را روی سرور خارجی حذف کنید؛ پراکسی Cloudflare Worker هم لازم نیست.

### اتصال به صفحهٔ اول قالب (Bazaar Terminal یا هر قالب دیگر)

افزونه خودش چیزی را در صفحهٔ اول قالب عوض نمی‌کند. سه راه:

1. اگر صفحهٔ اول با ویرایشگر ساخته شده: بلوک «کد کوتاه» با `[damoon_scan tf="4h" theme="dark"]` جای بخش فعلی بگذارید.
2. در فایل قالب (مثلاً `front-page.php`)، جای HTML ثابت بخش «اسکن زندهٔ ربات»:
   ```php
   <?php echo do_shortcode( '[damoon_scan tf="4h" theme="dark"]' ); ?>
   ```
3. برای حفظ طراحی خود قالب، داده را مستقیم بخوانید:
   ```php
   <?php foreach ( function_exists( 'damoon_sig_scan_items' ) ? damoon_sig_scan_items( '4h' ) : array() as $it ) : ?>
       <!-- $it['symbol'], $it['price'], $it['change_24h'], $it['direction'] (long | short | null = خنثی) -->
   <?php endforeach; ?>
   ```

### رفتارهای مهم

- **یک سیگنال باز برای هر نماد و تایم‌فریم.** تا وقتی سیگنال بازی برای مثلاً BTCUSDT · 1h وجود دارد، ستاپ تازه‌ای برای آن در کارنامه ثبت
  نمی‌شود (کاربر همچنان تحلیل را می‌بیند). این‌طور اسکن خودکار و درخواست‌های پشت‌سرهم، آمار را با سیگنال‌های تکراری باد نمی‌کنند.
- سیگنال‌ها هرگز حذف یا ویرایش نمی‌شوند.
- زمان «بسته‌شدن» هر سیگنال، زمان بسته‌شدن کندلی است که نتیجه در آن مشخص شد.

## تنظیمات (دامون سیگنال ← تنظیمات)

### تلگرام

1. با [@BotFather](https://t.me/BotFather) یک ربات بسازید و توکن را بگیرید.
2. ربات را ادمین کانال کنید.
3. توکن و شناسهٔ کانال (`@my_channel` یا `-100…`) را وارد و «ارسال به تلگرام» را تیک بزنید.
4. دکمهٔ «ارسال پیام آزمایشی تلگرام» را بزنید.

اگر هاست به تلگرام دسترسی ندارد، آدرس Worker را در «آدرس API تلگرام» بگذارید.

### سایت دامون (Next.js)

1. روی سرور سایت یک کلید جدا بسازید و به `BOT_API_KEYS` اضافه کنید (کلیدهای قبلی ربات را نگه دارید):
   ```bash
   openssl rand -hex 32
   # BOT_API_KEYS=bot1:<secret-ربات>,wp1:<secret-جدید>
   ```
2. در افزونه: آدرس سایت (`https://…`)، شناسهٔ کلید `wp1` و همان secret را وارد کنید و «ارسال به سایت دامون» را تیک بزنید.
3. دکمهٔ «تست اتصال سایت دامون» کلید، امضا و اختلاف ساعت را بررسی می‌کند.

| رویداد وردپرس | رویداد ارسالی |
|---|---|
| ثبت ستاپ تازه | `signal.new` با `orderType=MARKET` و `externalId=wp:<شناسهٔ نصب>:<id>` |
| رسیدن به هدف / حد ضرر / انقضا | `signal.closed` با `reason` برابر `TP` / `SL` / `MANUAL` |

> ⚠️ سایت دامون فعلاً منبع سیگنال‌ها را از هم جدا نمی‌کند. ستاپ‌های کاغذی کریپتو در فید مشترکین و صفحهٔ عملکرد، کنار سیگنال‌های
> ربات اصلی (XAUUSD و…) نمایش داده می‌شوند. اگر این را نمی‌خواهید، این گزینه را خاموش بگذارید.

### نگه‌داری secretها بیرون از دیتابیس (اختیاری)

در `wp-config.php`:

```php
define( 'DAMOON_TG_TOKEN', '123456:ABC…' );
define( 'DAMOON_SITE_SECRET', '…' );
```

### دسترسی و افزونه‌های عضویت

«دسترسی به ستاپ‌ساز» سه حالت دارد: همه، فقط کاربران واردشده، فقط نقش‌های انتخاب‌شده. هر افزونهٔ عضویتی که به مشترکین نقش
می‌دهد (مثلاً MemberPress یا Paid Memberships Pro) با حالت سوم کار می‌کند. برای منطق دلخواه:

```php
add_filter( 'damoon_sig_can_use', function ( $ok, $user_id ) {
	return $ok && my_membership_is_active( $user_id );
}, 10, 2 );

// متن دلخواه برای کسانی که دسترسی ندارند (مثلاً لینک خرید اشتراک):
add_filter( 'damoon_sig_denied_html', function ( $html, $logged_in ) {
	return '<p>برای استفاده از ستاپ‌ساز <a href="/pricing">اشتراک تهیه کنید</a>.</p>';
}, 10, 2 );
```

اگر افزونهٔ کش صفحه دارید، صفحهٔ ستاپ‌ساز را از کش مستثنا کنید تا پیام دسترسی برای مهمان و عضو قاطی نشود.
دسترسی واقعی همیشه سمت سرور (REST) بررسی می‌شود.

## کرون

ارزیابی (ساعتی)، اسکن (۱۵ دقیقه) و صف ارسال (۵ دقیقه) با WP-Cron اجرا می‌شوند. WP-Cron فقط با بازدید سایت راه می‌افتد.
برای دقت بیشتر در `wp-config.php` بنویسید `define( 'DISABLE_WP_CRON', true );` و در کرون سرور (یا cPanel ← Cron Jobs) اضافه کنید:

```
*/5 * * * * curl -s https://your-site.com/wp-cron.php?doing_wp_cron > /dev/null
```

زمان اجرای بعدی هر کار در صفحهٔ تنظیمات افزونه نمایش داده می‌شود.
